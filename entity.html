Entity — referência

Entity representa uma entidade da cena. Tudo que você faz com ela passa pela API — sem expor detalhes internos.

Propriedades

MembroTipoDescrição
Entity.InvalidEntityHandle inválido (não existe)
IsValidboolHandle != 0
IduintIdentificador numérico
NamestringNome (Tag) — leitura e renomeio em runtime
Entity e = Scene.CreateEntity("Jogador");
e.Name = "Herói";
Log.Info($"Id={e.Id}, nome={e.Name}, válida={e.IsValid}");

Estrutura Transform

public struct Transform
{
    public Vector3 Translation;
    public Vector3 Rotation; // euler, radianos
    public Vector3 Scale;
}
Rotação em radianos. A API C# usa sempre radianos (o Inspetor mostra em graus). Converta com graus * MathF.PI / 180f.
