Partículas

Emissor de partículas GPU-instanced com billboarding. Fogo, faíscas, magia, fumaça — tudo com o mesmo componente.

ParticleSystemComponent

CampoDescrição
PlayingEmissor ligado?
Additivetrue = aditivo (fogo/faísca/magia); false = alpha normal (fumaça)
EmissionRatePartículas por segundo
MaxParticlesTeto de partículas vivas
LifetimeMin / LifetimeMaxVida das partículas (aleatória no intervalo)
VelocityMin / VelocityMaxVelocidade inicial (aleatória no intervalo)
GravityAceleração aplicada às partículas
StartColor / EndColorCor interpolada ao longo da vida
StartSize / EndSizeTamanho interpolado
TexturePathTextura opcional (vazia = degradê radial procedural)

Exemplos de receitas

EfeitoConfiguração
FogoAdditive on, cor 1.0,0.65,0.15 → 1.0,0.15,0.02, gravidade −2
FumaçaAdditive off, cinza claro, tamanho crescendo
FaíscasAdditive on, amarelo, gravidade −9
MagiaAdditive on, StartColor azul/ciano, EndColor transparente

Em C#

var fogo = Scene.CreateEntity("Fogo");
fogo.AddMeshRenderer("builtin:cube"); // ainda não há AddParticles no C#
fogo.SetParticleTexture("Assets/Textures/faisca.png"); // textura opcional
Simula no Play. Partículas (como física e áudio) só emitem durante o Play — no modo de edição o emissor fica parado.

No editor

  • Ajuste os campos no Inspetor e veja o efeito em tempo real durante o Play;
  • Modo aditivo é uma checkbox (fogo/faíscas = aditivo; fumaça = normal);
  • Sem textura, o degradê radial procedural já dá um resultado bom para

partículas suaves.
